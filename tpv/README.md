# TPV package — этап 11.1

Текущая структура:

```text
tpv/
├── __init__.py
├── bootstrap.py
├── archive.py
├── archive_runtime.py
└── theme_engine.py
```

## Что перенесено

- ORM и API архива игр;
- Runtime автоматического сохранения;
- Theme Engine и Visual Theme Designer backend.

## Что пока остаётся в `game.py`

- модели основной игры TPV;
- маршруты игрока, ведущего и зрителя;
- Socket.IO-обработчики TPV;
- TPV Editor этапов 1–10.1, находящиеся непосредственно в `game.py`;
- код игры «Свободный слот».

Это сознательное ограничение этапа 11.1. Следующие этапы будут
переносить модели, маршруты и Socket.IO по отдельности, сохраняя
существующие URL и имена событий.
